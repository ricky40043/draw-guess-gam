# 你畫我猜（你說我畫 · 大家猜）

架構沿用 bingo-game：Go + Gin + Gorilla WebSocket、Vue 3 + TypeScript + Vite + Pinia，單一容器同時提供前端、API 與 WebSocket。

## 開始玩

```bash
./start.sh
```

需要 Go 1.21+、Node.js 20.19+。白板開啟 http://localhost:3346。手機需和電腦連同一個 Wi-Fi，**白板頁面請用 http://電腦區網IP:3346 開啟**，QR Code 才會帶到手機連得到的網址。前端用 3346、後端用 8083，不會和 bingo（3345 / 8082）衝突。

## 玩法

1. 白板電腦（建立房間的那台）選擇模式、回合數、每回合時間（60 秒–3 分鐘或不限時）、加入方式，建立房間後顯示 QR Code。
2. 大家用手機掃 QR Code 加入。分組賽要先選組；大廳裡選錯組可以退出重選。遊戲進行中也能掃白板右下角的 QR Code 中途加入。
3. 每回合輪一個人當**描述者**：他的手機會顯示一張簡單線條圖（例如車子、烏龜、房子）和名稱，只能用講的形容「怎麼畫」，不能說出答案。
4. 其他人在手機上照著描述畫，同時可以打字猜答案；用喊的猜中時，由描述者或白板點那個人的畫面「判定答對」。
5. 描述者和白板即時看到所有人的畫。可「換一題」（還沒人答對時才可以）或提前「結束本回合」。時間到、全員答對或按下結束時揭曉答案，所有人都會看到所有作品。
6. 描述者或白板按「下一回合」換下一個人；最後一回合結束後顯示排行榜，白板可以「再玩一場」（保留玩家、分數歸零）。

### 個人賽

- 除了描述者，所有人都要畫。畫畫的人看不到別人的畫（避免互相抄）。
- 答對依順序得 **3 / 2 / 1** 分（第三名之後都是 1 分）；只要有人猜對，描述者就 +1（每回合只加一次）。
- 所有在線玩家都答對時自動揭曉。
- 描述者依加入順序輪流，離線的人會跳過。

### 分組賽（2–8 組）

- 各組輪流；輪到的那組由一位組員描述（組內依序輪流），其餘組員畫，**組員可以在自己的畫布下方看到彼此的畫**。
- 其他組不用畫，手機直接看到輪到那組的所有畫，可以搶答。
- **第一個答對的人結束本回合**：同組猜對 → 該隊共 +5（猜對者 +3、描述者 +2）；別組搶答 → 搶答隊 +3、畫的那隊 +2（記在描述者）。隊伍分數是組員分數加總。
- 開始條件：至少 2 組有人，而且至少一組有 2 人以上；人數少於 2 人的組會被跳過。

## 題庫

`backend/prompts.json` 內建 300 題，每題包含名稱、別名與線條 SVG（viewBox 0 0 100 100，只用線條不填色）。打字猜題會忽略空白、標點、全形與大小寫，並接受別名（例如「汽車」＝「車子」、「單車」＝「腳踏車」）。測試會檢查題數和別名沒有跨題重複。

新增題目時只要在 JSON 加一筆；SVG 屬性請用單引號，畫好後最好開瀏覽器看一下是否一眼認得出來。

## 連線與狀態

- 房號是 4 位數字（0000–9999），方便口頭報給大家；手機也可以在首頁輸入房號加入。
- 一般狀態以 `state` 事件推送整包快照；**筆跡**是高頻資料，另外用 `ink` 事件只轉送給看得到那張畫的人（白板、描述者；分組賽則是全房），不會跟著每次廣播重送。
- 畫布座標統一正規化到 0–1000，前端每 60 ms 批次送出一次。每人每回合最多 30,000 個點、800 筆。
- 答案只會送給描述者與白板；揭曉前畫畫的人收到的資料裡沒有答案。
- 重新整理或短暫斷線會用分頁 sessionStorage 的憑證自動回到房間，並補回目前的畫布。
- 資料只存在記憶體，服務重啟會清空；單一後端實例部署。房間無人連線且閒置 2 小時後清除。最多 300 人 / 房、500 房。

## 驗證

```bash
cd backend && go test -race ./...
cd ../frontend && npm ci && npm run build
```

## Docker 部署

```bash
cp .env.example .env   # 填入 FRONTEND_URL（實際 HTTPS 網址）
docker compose up -d --build
```

主機對外連接埠預設為 `20941`，容器內 8083。對外部署請用支援 WebSocket Upgrade 的 HTTPS 反向代理或 Cloudflare Tunnel。

## 目錄與協定

- `backend/game.go`：設定驗證、輪流、計分、筆跡儲存與限制。
- `backend/main.go`：房間、憑證、WebSocket、筆跡轉送、倒數計時、靜態檔案。
- `backend/prompts.go`、`prompts.json`：題庫與答案比對。
- `frontend/src/store.ts`：連線、身分恢復、筆跡同步。
- `frontend/src/components/InkCanvas.vue`：畫布（增量繪製，可編輯或唯讀）。
- `frontend/src/views/`：建立、加入、大廳、遊戲中、結算畫面。

客戶端指令：`create {settings}`、`join {room,name,group}`、`resume {room,token}`、`leave`、`start`、`guess {text}`、`award {id}`、`skip`、`end_turn`、`next`、`end`、`reset`、`ink {t,s,c,w,pts}`、`undo {t}`、`clear {t}`。
伺服器事件：`session`、`state {room,me,host,prompt,now}`、`ink`、`canvas`、`canvases`、`error`、`left`。房間狀態：`lobby → playing → finished → lobby`；回合階段：`drawing → reveal`。
